# أسئلة مفتوحة تحتاج تأكيداً لاحقاً

> مسجّلة بناءً على ما فحصه التنفيذ ولم يُفترض. لا نحاول تخمينها.

## قائمة الطعام
- [ ] هل توجد أحجام/متغيرات (مثل حجم بيتزا) وأسعار متعددة لنفس الصنف؟
- [ ] هل توجد إضافات/معدّلات (Modifiers) مع مجموعات وقواعد (إلزامي/اختياري، حد أدنى/أقصى)؟
- [ ] هل تريد استيراد روابط الصور الموجودة أم إدارة الصور داخل النظام؟
- [ ] هل يحتاج الوصف/المكونات لعرضه للعميل/المطبخ؟

## مالية
- [ ] هل تطبق ضريبة/خدمة؟ إن نعم، هل هي نسبة ثابتة، قابل للتفعيل/التعطيل لكل حالة، وترتيب الحساب؟
- [ ] هل هناك خصومات (بنسبة/مبلغ ثابت) مع صلاحيات؟
- [ ] عملة افتراضية؟ الملف يستخدم ل.س (ليرة سورية). النظام سيجعلها قابلة للتكوين مع افتراضي `SYP`.

## الطباعة
- [ ] موديل طابعة الكاشير (USB) وطابعة المطبخ (USB/شبكة/IP)؟
- [ ] نوع ورق (حراري 80mm / غيره)؟
- [ ] هل الطباعة مطلوبة "مرة واحدة بالضبط" أم "محاولة مع تأكيد حالة"؟

## أجهزة وشبكة
- [ ] عدد الأجهزة الفعلي وأنواعها (4 نادل + مطبخ + كاشير)؟
- [ ] نظام تشغيل جهاز الكاشير (Windows/Linux)؟
- [ ] هل يوجد إنترنت في الموقع أم فقط LAN؟

## تقني
- [ ] تفضيل PostgreSQL أم SQLite للتشغيل المحلي؟
  - ملاحظة التنفيذ: نُفضّل PostgreSQL للتزامن المتعدد للأجهزة، لكن سنصمم بحيث يمكن التكوين. سنبدأ بتكوين جاهز لـ Postgres مع إمكانية تعديل عبر `.env`.
- [ ] إدارة جلسات (Server sessions) أم JWT؟
